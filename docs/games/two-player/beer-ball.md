# Beer Ball

| | |
| --- | --- |
| **Format** | 2-player teams (5 teams of 2) |
| **Rounds** | 2024: each team played twice on a session schedule |
| **Teams** | Same teams as the game it is paired with |
| **Points** | 2024: 5 points per player per win |
| **Drinking** | Yes |
| **Played** | 2024 (paired with [Spikeball](spikeball.md)) |

## Setup

- Each team has two beers, one on each corner of their side of the table.

## Rules

- A player from team X throws across the table to hit team Y's beers.
- When a can is hit, the **other** player from team X drinks until team Y slams the ball on the table.
- Turn order is X1, Y1, X2, Y2.
- First team to finish their beers wins.
- If you knock your own can over, start a new beer.

## Supplies

- Table, ping pong balls, 12 oz canned beer

## 2024 session schedule

Run alongside Spikeball so two matches happen at once. Captains are numbered 1 to 5.
