# Egg Toss

| | |
| --- | --- |
| **Format** | 2-player teams (5 teams of 2) |
| **Rounds** | 1 |
| **Teams** | Same teams as the game it is paired with |
| **Points** | 2024: 1st 6, 2nd 4, 3rd 3, 4th 1, 5th 0 · IDP Max: 6 |
| **Drinking** | No (tie breaker only) |
| **Played** | 2024 (paired with [Blind Beer](blind-beer.md)) |

## Rules

- Each team lines up 20 feet apart from their teammate with one egg.
- All teams throw at the same time, and keep going until their egg breaks.
- The team whose egg lasts longest wins.
- Tie breaker is a 2-drink-per-team chug off.

## Supplies

- 5 eggs (plus spares)
