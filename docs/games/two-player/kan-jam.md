# Kan Jam

| | |
| --- | --- |
| **Format** | 2-player teams (5 teams of 2) |
| **Rounds** | Round robin: your team plays each other team once (4 games) |
| **Teams** | Bottom 5 players are captains and each picks a non-captain. Lowest captain picks first. |
| **Points** | Standard 2-player: 1st 9 per player, 2nd 7, 3rd 5, 4th 2 (by most wins) |
| **Drinking** | No |
| **Played** | 2025 |

Runs well side by side with [Spikeball](spikeball.md) using the same teams. Official reference: [How to play Kan Jam](https://www.kanjam.com/pages/how-to-play).

## Setup

- Set the Kans opposite one another, 50 feet apart.

## Rules

- Partners stand at opposite Kans (like cornhole).
- Rock, paper, scissors (on shoot) for who goes first.
- Teams alternate turns. One player throws, and their partner at the Kan deflects the disc toward it.
- Both teams always get the same number of turns, so the team going second gets a chance to answer. The only exception is an instant win.
- Score **exactly 21** to win. Going over drops your score back to what it was before that throw.
- **Overtime:** if both teams reach 21 on the same turn, each team gets one more round. High score wins. Repeat if still tied.
- **Tied records:** decided by the head-to-head game.

## Scoring

| Shot | Points | How |
| --- | --- | --- |
| Dinger | 1 | Deflector redirects the disc to hit the Kan |
| Deuce | 2 | Throw hits the Kan without deflection |
| Bucket | 3 | Deflector redirects the disc into the top of the Kan |
| Instant Win | Game over, no rebuttal | Throw goes through the front slot unassisted |

## Supplies

- Kan Jam set (2 Kans, disc)
