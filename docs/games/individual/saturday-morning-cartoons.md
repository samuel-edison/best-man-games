# Saturday Morning Cartoons

| | |
| --- | --- |
| **Format** | Individual |
| **Rounds** | Each player plays once. Order is picked by the prior year's Best Man. |
| **Points** | Standard solo: 1st 9, 2nd 8 … 9th 1, 10th 0 · IDP Max: 9 |
| **Drinking** | No |
| **Played** | 2025 |

A video game played one at a time. A good opener to establish initial rankings.

## Rules

- Each player plays the game once. Highest score wins.
- The player who goes next gets to watch the current player play.
- The first player has the disadvantage of not getting to watch anyone.

## Supplies

- Xbox, controller, controller charger
