A video game played one at a time. A good opener to set the first rankings.

## Rules

- The prior year's Best Man sets the playing order.
- Each player plays the game once. Highest score wins.
- The next player in line watches the current player. The first player goes in blind.

## Supplies

- Xbox, controller, controller charger
