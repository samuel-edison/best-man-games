# Chug Norris

| | |
| --- | --- |
| **Format** | Individual (1 v 1 matchups) |
| **Rounds** | Each player chugs once |
| **Matchups** | Hat draw |
| **Points** | 2024: each matchup winner gets 2 points, plus bonus · IDP Max: 4 |
| **Drinking** | Yes |
| **Played** | 2024 (paired with [Stein Hold](stein-hold.md)) |

## Rules

- Players chug their drink head-to-head.
- Prove you finished by turning the can or cup upside down over your head.
- There should be minimal, slow drip at most. Anything more is immediate disqualification and a loss.

## Bonus

- 2 points for the fastest overall chug.

## Supplies

- Solo cups or beer cans
- Stopwatch
