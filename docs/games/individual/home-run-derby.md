# Home Run Derby

| | |
| --- | --- |
| **Format** | Individual |
| **Rounds** | Each player bats once (10 swings) |
| **Points** | Standard solo: 1st 9, 2nd 8 … 9th 1, 10th 0 · IDP Max: 9 |
| **Drinking** | No |
| **Played** | Not yet (new for 2026) |

Wiffle ball home run derby, using the kickball corner of the [shared field](../five-player/field-setup.md#kickball).

## Setup

- **Home plate** goes on the kickball home corner. The sideline and end line are the foul lines.
- **Pitcher** stands at the kickball pitcher's spot, 14 yd from home.
- Put out two rows of cones across fair territory to mark the scoring zones:

| Ball first lands | Points |
| --- | --- |
| Short of 20 yd (inside the bases) | 0 |
| Past 20 yd (the bases) | 1 |
| Past the 35 yd cones | 2 |
| Past the 50 yd cones (home run) | 3 |

## Rules

- **Batting order:** reverse standings, so the current leader bats last.
- **Pitching:** underhand and hittable. The pitcher is whoever bats next.
- You get **10 swings**. A swing and a miss counts as a swing. You don't have to swing at a bad pitch.
- **Fair or foul:** the ball must first land between the foul lines. A foul ball scores 0 but still uses a swing.
- Points come from **where the ball first lands**, not where it rolls.
- Highest total after 10 swings wins.
- **Ties:** tied players each get 3 more swings, repeating until the tie is broken.

## Supplies

- Wiffle ball bat and several wiffle balls
- Cones for the 35 yd and 50 yd zone lines
- Tape measure
