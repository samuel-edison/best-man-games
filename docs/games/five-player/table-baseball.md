# Table Baseball

| | |
| --- | --- |
| **Format** | 5-player teams (5 v 5) |
| **Rounds** | 5 innings |
| **Teams** | [Picked Friday night](../../rules/scoring.md#picking-teams) from last year's rankings |
| **Points** | Standard 5v5: 9 per winner |
| **Drinking** | Yes |
| **Played** | 2024 (listed as "Baseball") |

Baseball played on a beer pong table. Not to be confused with [Beerball-Baseball](beerball-baseball.md), which uses a bat.

## Setup

- Each team lines up four cups in a row on their end of the table.
- Each cup is a base: the closest cup is 1st base, the furthest is home.
- Each team also places one cup a foot away from their opponent's cups, used for stealing bases.

## Rules

- Each team gets 3 outs per inning.
- An **out** is when:
    - The ball misses the table entirely (no bounce)
    - The ball bounces off a cup and is caught before hitting the table
- A **strike** is when the ball hits the table.

## Supplies

- Solo cups, beer, ping pong balls, table
