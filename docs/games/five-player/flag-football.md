# Flag Football

| | |
| --- | --- |
| **Format** | 5-player teams (5 v 5) |
| **Rounds** | 1 |
| **Teams** | [Picked Friday night](../../rules/scoring.md#picking-teams) from last year's rankings |
| **Points** | Standard 5v5: 9 per winner · IDP Max: 10 (with bonus) |
| **Drinking** | No |
| **Played** | 2025 |

## Setup

See **[Field Setup](field-setup.md)** for the shared field diagram and measurements.

- Same field as [Ultimate Frisbee](ultimate-frisbee.md): 50 yards long including 5-yard end zones, 25 yards wide.
- First down line is the 25-yard line, which is **midfield** (yards are counted from the end line).
- The starting spot is the 5-yard line, which is each team's **own goal line**.

## Rules

- **No kickoffs.** Every drive starts at the offense's own 5-yard line.
- **Downs:** you get 4 downs to reach the first down line at midfield (the 25-yard line), then 4 more to score.
- **Pass rush:** count 3 Mississippi before rushing the QB. If the QB hands off or pitches to another player, you can rush right away.
- **Linemen:** the offense can use as many as they want.
    - Before the snap, a lineman takes off their flag to show they're blocking only.
    - Linemen block with their hands behind their back.
    - Linemen can't catch or carry the ball.
- First team to 3 touchdowns wins.

## Bonus

- 1 point for MVP (most touchdowns plus interceptions). Must be on the winning team.

## Supplies

- Pinnies, football, cones for the field, flags
