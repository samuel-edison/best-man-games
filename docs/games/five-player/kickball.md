# Kickball

| | |
| --- | --- |
| **Format** | 5-player teams (5 v 5) |
| **Rounds** | 1 game, 5 innings |
| **Teams** | Bottom 2 players are captains. Bottom player picks first. |
| **Points** | Standard 5v5: 9 per winner · IDP Max: 11 (with bonuses) |
| **Time** | About 1 hour |
| **Drinking** | No |
| **Played** | 2024, 2025 |

## Setup

- Use cones to create the field.
- 60 feet between bases.
- 42 feet from home to the pitcher's mound.
- Bunt line 20 feet from home.

## Rules

- Standard kickball rules. Catch the ball or hit the runner with it for an out.
- 5 innings.
- Outs:
    - 2 strikes (missed kicks) is a strikeout.
    - 3 fouls is an out, as is 1 strike and 2 fouls.
- Bunts must reach the 20-foot line or they count as a foul.
- Mercy rule: max 5 runs per team per inning, except the last inning.

## Bonus

- 1 point for a double play, max one per player per game.
- 1 point for a home run, max one per player per game.

## Supplies

- Pinnies, kickball, cones for bases, tape measure

## Year notes

- **2024:** 2 points per winner, and bonuses were worth 2 points each (IDP Max 6).
