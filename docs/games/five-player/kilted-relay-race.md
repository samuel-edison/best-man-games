# Kilted Relay Race

| | |
| --- | --- |
| **Format** | 5-player teams (5 v 5) |
| **Rounds** | Best 2 of 3 |
| **Teams** | Bottom 2 players are captains. Bottom player picks first. |
| **Points** | Standard 5v5: 9 per winner |
| **Time** | About 20 minutes |
| **Drinking** | Light |
| **Played** | 2024 |

A team relay built from [Obstacle Course](../individual/obstacle-course.md) stations. Rename it to match the year's theme.

## Rules

- 5 checkpoints. Each player takes one, relay style.
- Both teams start at the same time. First team to finish all 5 wins the round.
- Each checkpoint is a simple, funny challenge (tossing a small caber, jumping mini obstacles, balancing a small weight).

## Course

Start by the kickball area, near the disc golf hole 1 tree. Stations used in 2024:

- Partner carry
- Beer pong (see Obstacle Course)
- Ping pong ball on spoon (see Obstacle Course)

## Supplies

- Similar to the Obstacle Course. Decide stations as a group beforehand.

## Year notes

- **2024:** 2 points per winner per round (IDP Max 4). Captains were the top players that year rather than the bottom.
