# Beerball-Baseball

| | |
| --- | --- |
| **Format** | 5-player teams (5 v 5) |
| **Rounds** | 1 game |
| **Teams** | [Picked Friday night](../../rules/scoring.md#picking-teams) from last year's rankings |
| **Points** | Standard 5v5: 9 per winner |
| **Drinking** | Yes |
| **Played** | 2025 |

## Setup

- Set up a cooler. The batter stands at the cooler.
- Put the pitcher's cone 15 feet from the cooler.

## Rules

- Only the batting team drinks. The fielding team doesn't.
- The lower-ranked captain's team bats first.
- **Pitching:** underhand and hittable. You're not trying to strike anyone out.
- **Hit:** the **batter and the next batter in the lineup** both chug until the fielding team touches the ball to the cooler (by throwing it at the cooler or carrying it there).
- **Outs:**
    - The fielding team gets the ball to the cooler.
    - 3 strikes.
- **Runs:** every beer finished is a run. Finish one, grab a new one and keep going. Only finished beers count.
- **Switching sides:** after 3 outs, like normal baseball.
- **Winning:** first team to finish 5 beers. If the team that batted first gets there first, the other team gets one more turn at bat to catch up.

## Supplies

- Cooler, bat, pickleball, cone, beer
