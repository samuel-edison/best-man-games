# Hanabi

| | |
| --- | --- |
| **Format** | 5-player teams (5 v 5) |
| **Rounds** | 1 per team |
| **Teams** | Bottom 2 players are captains. Bottom player picks first. |
| **Points** | Standard 5v5: 9 per winner |
| **Drinking** | No |
| **Played** | 2024 |

## Rules

- Each team plays one game of Hanabi, following the game's rules.
- Higher Hanabi score wins.
- Giving away more information than a clue allows (a hint in your voice, face, or extra words) takes 1 point off your team's score.

## Supplies

- Hanabi card game

## Year notes

- **2024:** 2 points per winner (IDP Max 2). Captains were the top 2 players. Running totals were kept secret from this game until the end.
