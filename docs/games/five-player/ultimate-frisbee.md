# Ultimate Frisbee

| | |
| --- | --- |
| **Format** | 5-player teams (5 v 5) |
| **Rounds** | 1 |
| **Teams** | [Picked Friday night](../../rules/scoring.md#picking-teams) from last year's rankings |
| **Points** | Standard 5v5: 9 per winner · IDP Max: 10 (with bonus) |
| **Time** | About 30 minutes |
| **Drinking** | No |
| **Played** | 2024, 2025 |

Uses the same field as [Flag Football](flag-football.md), so schedule them back to back.

## Setup

See **[Field Setup](field-setup.md)** for the shared field diagram and measurements.

- 50 yards long (including end zones), 25 yards wide.
- 5-yard end zones.

## Rules

- Standard ultimate rules. Pass the frisbee to move toward the end zone, and catch it in the end zone to score.
- No running with the frisbee. Pivoting only.
- A dropped, blocked, intercepted, or out-of-bounds pass is a turnover.
- **Make it, take it:** after a score, the scoring team keeps the disc and goes straight at the other end zone. Play doesn't stop.
- First team to 4 points wins.

## Bonus

- 1 point for MVP (most assists plus goals). Must be on the winning team.

## Supplies

- Pinnies, frisbee, cones for the field

## Year notes

- **2024:** 2 rounds with different teams, first to 3 points, 2 points per winner per round, and a 2-point MVP bonus.
