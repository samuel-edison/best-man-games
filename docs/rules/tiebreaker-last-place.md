# Tie Breaker & Last Place

## Tie breaker

If players are tied on total points at the end, they play **one-on-one beer pong**.

- Each player gets two shots per turn.
- All other [Beer Pong](../games/two-player/beer-pong.md) rules apply.

## Last place

The two last-place players compete in a last place game. The game changes by year:

| Year | Last place game |
| --- | --- |
| 2025 | [Rap Battle](../games/individual/rap-battle.md) |
| 2024 | [Highland Dance-Off](../games/individual/highland-dance-off.md) |
