# 2025

## Event details

| | |
| --- | --- |
| **Attire** | White Trash / Trailer Park outfit |
| **Game time** | Saturday, 8:30 AM (or sooner if possible) until sunset, around 5 PM |
| **Food** | Breakfast burritos, hot dogs, burgers |
| **Bring** | Sleeping bag, koozie, tent (if sleeping outside), costume, 30 pack of light beer or equivalent, anything else you want for yourself |
| **Award** | T-shirt customized for the year and/or name on the victors plaque |
| **Last place** | [Rap Battle](../games/individual/rap-battle.md) between the bottom two |
| **Tie breaker** | [One-on-one beer pong](../rules/tiebreaker-last-place.md) |

All [General Rules](../rules/index.md) apply, including [Power Plays](../rules/power-plays.md) (new this year) and [Bonus Chugs](../rules/bonus-chugs.md).

## Points

The [standard point system](../rules/scoring.md):

- **5v5:** 9 per winner
- **2v2:** 1st 9, 2nd 7, 3rd 5, 4th 2
- **Solo:** 1st 9, 2nd 8 … 9th 1, 10th 0
